==========================================================
 BTA-COCKPIT - DER STICK (ein Werkzeug fuer alles)
==========================================================
Stand: 30.10.2026 (Programm 1.3, Dienst 0.6.1, Werkzeug neu)

Dieser Ordner enthaelt ALLES, um das BTA-Cockpit auf einem
Windows-Rechner einzurichten - und den BTA-Server zu pflegen.
Keine Adminrechte am Rechner, keine IT-Anfrage noetig.

----------------------------------------------------------
 SO GEHT ES - DREI KLICKS
----------------------------------------------------------
1. Doppelklick auf  BTA-Werkzeug.cmd
   (Das schwarze Fenster blitzt nur kurz auf, dann kommt
   ein richtiges Fenster.)
2. Schritt 1: Das Werkzeug schaut sich um und zeigt, was es
   gefunden hat (Stick, Laufwerk oder Server, Cockpit da?).
   -> "Weiter"
3. Schritt 2: EINE Frage - Wofuer ist dieser Rechner?
     Arbeitsplatz in der Werkstatt
     Info-Bildschirm (Morgenrunde)  = Autostart + Vollbild
     Nur ansehen
   -> "Einrichten"
4. Schritt 3: Gruener Haken = fertig. "Cockpit jetzt oeffnen".
   Windows-SmartScreen meldet sich nur beim allerersten
   Start: "Weitere Informationen" -> "Trotzdem ausfuehren".

Mehr muss niemand wissen. Pfade, Verbindungsweg und Standort
stehen auf dem Stick (02-Einstellungen). Ist etwas nicht in
Ordnung, sagt es das Werkzeug in einer roten Zeile mit dem
einen naechsten Schritt.

----------------------------------------------------------
 "MEHR ..." - DIE TAFEL (fuer Roberto und Vertretung)
----------------------------------------------------------
Unten links im Fenster. Je Zeile eine Ampel (Programm,
Verbindung, Verknuepfung, Autostart, neueste App-Fassung,
Server) und ein Knopf, der genau das richtet. "Alles
einrichten, was fehlt" macht alles Rote auf einmal. Darunter:
Server-Weg ein/aus, Pfade neu speichern, Programm laden,
Datenordner oeffnen, Vom Rechner entfernen.

----------------------------------------------------------
 AUF DEM BTA-SERVER
----------------------------------------------------------
Dasselbe BTA-Werkzeug.cmd, aber: Rechtsklick -> "Als
Administrator ausfuehren". Das Werkzeug erkennt den Server
selbst und fragt in Schritt 2: Dienst einrichten/tauschen,
App-Datei tauschen, Sicherung jetzt, Sicherung einspielen.
"Mehr ..." zeigt die neun Server-Ampeln, Dienst starten/
stoppen, Status-Seite, Import von W:, Vom Server entfernen.
Einzelheiten: 05-Server\LIESMICH-SERVER.txt

----------------------------------------------------------
 WAS LIEGT WO?
----------------------------------------------------------
BTA-Werkzeug.cmd      das Werkzeug (Doppelklick)
werkzeug\             die drei Skripte dahinter (bta-kern,
                      bta-fenster, bta-werkzeug)
01-Programm\          das Programm als ZIP (ca. 110 MB)
02-Einstellungen\     Pfade, verbindungsweg.txt (datei/server)
                      und die Erklaerungen dazu
03-Anleitung\         die Aufsetz-Anleitung als PDF
04-Download-Links\    alle Download-Adressen
05-Server\            Dienst + node.exe + server-adresse.txt

----------------------------------------------------------
 GUT ZU WISSEN
----------------------------------------------------------
- Leser-Rechner werden GENAU GLEICH eingerichtet. Ohne
  Schreibrecht schaltet die App von selbst auf "nur ansehen".
- Updates kommen NICHT ueber diesen Stick: Sobald eine neue
  Werkstatt_Kalender_TPM.html im Update-Ordner liegt, meldet
  sich im Programm der gruene Balken (Datei-Weg); am Server-
  Weg kommt die neue Fassung beim naechsten Oeffnen.
- Umschalttag auf den Server: in 02-Einstellungen die Datei
  verbindungsweg.txt auf "server" stellen, Stick neu bespielen.
- Der Stick wird gebaut mit:  node tools/stick-bauen.js --mit-server
  und geprueft mit:          node tests/pruefe-werkzeug.js
