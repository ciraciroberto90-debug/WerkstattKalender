==========================================================
 NOTFALLZETTEL - BTA-COCKPIT AUF DEM SERVER v-btacockpit-01
==========================================================
Stand: 30.09.2026 (Bauplan doku/BAUPLAN-SERVER-SYSTEM.md, Abschnitt 12)

Dieser Zettel ist fuer den Fall, dass niemand da ist, der das System
gebaut hat. Alles hier geht ohne Sonderwerkzeug - mit Explorer,
Eingabeaufforderung und Browser.

----------------------------------------------------------
 1. WO LIEGEN DIE DATEN?
----------------------------------------------------------
Auf dem Server v-btacockpit-01 (Freigabe \\v-btacockpit-01\BTA = C:\BTA):

  C:\BTA\BTA-Scheurich\cockpit.sqlite      Datenbank Scheurich (alles:
                                           Eintraege, Stoerberichte,
                                           Einstellungen, Verlauf)
  C:\BTA\BTA-Scheurich\fotos\              Fotos zu Berichten und Zetteln
  C:\BTA\BTA-Soendgen\...                  dasselbe fuer Soendgen
  C:\BTA\BTA-Sicherung\                    Sicherungen, jede Nacht 02:00:
      2026-09-30-02-00_scheurich.sqlite    Datenbank-Kopie (14 Tage)
      2026-09-30-02-00_scheurich_kalender.json     Export im Format der
      2026-09-30-02-00_scheurich_stoerungen.json   alten Datei-Fassung
  C:\BTA\BTA-Programm\Dienst\              der Dienst: node.exe, dienst.js,
                                           db.js, einstellungen.json,
                                           protokoll\dienst-JJJJ-MM-TT.log
  C:\BTA\BTA-Programm\App\                 die App (eine HTML-Datei)

Die Datenbank ist SQLite - ein offenes Format. Jedes SQLite-Werkzeug
(z. B. "DB Browser for SQLite") kann sie oeffnen. Die Tabellen heissen
eintraege, stoerungen, konfig, aenderungen; die Spalte "daten" traegt
den kompletten Eintrag als JSON.

----------------------------------------------------------
 2. LAEUFT DER DIENST?
----------------------------------------------------------
Im Browser: http://v-btacockpit-01:8765/status
  Kommt die Seite: er laeuft. Dort stehen Fassung, Stand je Standort,
  letzte Sicherung, Fehler der letzten 24 Stunden.
Kommt nichts: auf dem Server Aufgabenplanung oeffnen ->
  Aufgabenplanungsbibliothek -> "bta-cockpit-dienst" -> Rechtsklick ->
  Ausfuehren. Oder das BTA-Server-Werkzeug (Stick) -> Wartung ->
  "Dienst starten".

Von Hand starten (Eingabeaufforderung als Administrator):
  cd C:\BTA\BTA-Programm\Dienst
  node\node.exe --no-warnings dienst.js einstellungen.json
Das Fenster zeigt dann das Protokoll live. Beenden mit Strg+C.

----------------------------------------------------------
 3. EINE SICHERUNG ZURUECKSPIELEN (ohne Werkzeug)
----------------------------------------------------------
  a) Dienst stoppen: Aufgabenplanung -> bta-cockpit-dienst -> Beenden
     (oder Task-Manager: node.exe beenden).
  b) In C:\BTA\BTA-Scheurich\ die Dateien cockpit.sqlite,
     cockpit.sqlite-wal und cockpit.sqlite-shm in einen Unterordner
     "vor-rueckweg-DATUM" verschieben (nie loeschen).
  c) Aus C:\BTA\BTA-Sicherung die gewuenschte ..._scheurich.sqlite nach
     C:\BTA\BTA-Scheurich\cockpit.sqlite kopieren (umbenennen!).
  d) Dienst starten (Aufgabenplanung -> Ausfuehren).
  e) http://v-btacockpit-01:8765/status pruefen: Version und Zahlen
     entsprechen dem Stand der Sicherung.
Mit dem Werkzeug: Wartung -> "Sicherung einspielen..." macht a-e allein.

----------------------------------------------------------
 4. ZURUECK ZUR ALTEN DATEI-FASSUNG (Notbremse)
----------------------------------------------------------
Die alte Fassung des Cockpits arbeitet mit zwei JSON-Dateien. Der Dienst
liefert genau dieses Format:
  http://v-btacockpit-01:8765/api/scheurich/export.json
      -> als werkstatt-kalender-daten.json speichern
  http://v-btacockpit-01:8765/api/scheurich/export.json?bereich=stoerungen
      -> als werkstatt-stoerungen.json speichern
Beide Dateien in den Werkstatt-Ordner auf W: legen (den alten Ordner
vorher umbenennen, nie zwei lebende Kopien), Fotos aus
C:\BTA\BTA-Scheurich\fotos nach W:\...\Werkstatt_Kalender\Fotos.
Dann auf jedem Rechner die alte Programm-ZIP (Stick, 01-Programm) und
"Pfade speichern" im BTA-Cockpit-Werkzeug. Ohne Dienst: die naechtlichen
Exporte in C:\BTA\BTA-Sicherung sind dieselben Dateien.

----------------------------------------------------------
 5. EIN RECHNER KOMMT NICHT AN DEN SERVER
----------------------------------------------------------
  - Im Browser http://v-btacockpit-01:8765/status probieren, dann
    http://10.253.100.31:8765/status. Geht die zweite, ist der Name das
    Problem (IT: DNS). Geht keine: Firewall-Regel "BTA-Cockpit-Dienst" auf
    dem Server pruefen (Werkzeug -> Pruefen).
  - Das Cockpit arbeitet in der Zeit mit seinem oertlichen Spiegel weiter
    und schickt die Aenderungen, sobald der Server antwortet (rote Leiste
    -> gruene Meldung).
