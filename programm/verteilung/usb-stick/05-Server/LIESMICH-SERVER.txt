Dieser Ordner gehoert zum BTA-Server-Werkzeug (BTA-Server-Werkzeug.cmd
eine Ebene hoeher). Er wird NICHT von Hand benutzt.

  LIESMICH-NOTFALL.txt  Notfallzettel: wo die Daten liegen, Rueckweg
               ohne Werkzeug, Export ins alte Format, wen fragen
  dienst\      dienst.js, db.js, einstellungen.beispiel.json
               (der Dienst: Datenbank, Schnittstelle, Status-Seite,
               Sicherung - ohne Zusatzpakete, nur Node)
  node\        node.exe (Node v22.23.3 portabel, 83 MB) - fehlt es
               hier, laedt das Werkzeug es mit "Node herunterladen"
               von nodejs.org (braucht Internet auf dem Server).
               Die kleine Stick-ZIP aus dem Chat enthaelt node.exe
               NICHT (zu gross) - nur der volle Stick-Bau mit
               --mit-node legt es hierher.

So wird der Server eingerichtet (immer als Administrator):
  1. Stick an den Server (oder den Ordner per Remotedesktop
     hinueberkopieren).
  2. Rechtsklick auf BTA-Server-Werkzeug.cmd -> Als Administrator
     ausfuehren.
  3. Reiter Pruefen -> "Jetzt pruefen": alle Ampeln gruen oder gelb.
  4. Reiter Einrichten -> erst "Nur pruefen (Vorschau)", dann
     "Einrichten". Am Ende oeffnet sich die Status-Seite
     http://<servername>:8765/status (steht nach dem Einrichten in
     server-adresse.txt in diesem Ordner)

Was danach laeuft: Aufgabe "bta-cockpit-dienst" in der
Aufgabenplanung (Beim Systemstart, Konto SYSTEM, Neustart bei
Fehler), Firewall-Regel "BTA-Cockpit-Dienst" (TCP 8765 eingehend),
Dienst-Ordner C:\BTA\BTA-Programm\Dienst, Datenbanken
C:\BTA\BTA-Scheurich\cockpit.sqlite und C:\BTA\BTA-Soendgen\cockpit.sqlite,
Sicherungen nachts 02:00 nach C:\BTA\BTA-Sicherung.

Der Stick wird mit  node tools/stick-bauen.js --mit-server  gebaut;
--mit-node laedt zusaetzlich node.exe von nodejs.org in diesen Ordner.
