 GITHUB-RELEASE VEROEFFENTLICHEN (Robertos Handgriff)
==========================================================
Stand: 21.09.2026

Ziel: EIN Download-Link fuer alles. Danach heisst ein neuer
Rechner nur noch: Link -> entpacken -> Einrichten.cmd.
Dauert einmalig ca. 5 Minuten, laeuft komplett im Browser,
keine Adminrechte.

----------------------------------------------------------
 SCHRITT 1: Die eine ZIP-Datei bauen (am eigenen Rechner)
----------------------------------------------------------
Grundlage ist der fertige Paket-Ordner (der USB-Stick-Ordner
mit dem Programm-ZIP in 01-Programm; der Zettel
HIER-FEHLT-NOCH-DAS-PROGRAMM.txt muss raus sein).

1. Rechtsklick auf den Ordner BTA-Cockpit-USB-Stick
   -> "In ZIP-Datei komprimieren" (Windows 11)
      bzw. "Senden an -> ZIP-komprimierter Ordner" (Windows 10).
2. Die entstandene Datei EXAKT so umbenennen:

      BTA-Cockpit-Komplettpaket.zip

   WICHTIG: Der Name muss Buchstabe fuer Buchstabe stimmen,
   sonst laeuft der feste Download-Link (Weg 1 in
   DOWNLOAD-LINKS.txt) ins Leere.

----------------------------------------------------------
 SCHRITT 2: Release anlegen (im Browser)
----------------------------------------------------------
1. https://github.com/ciraciroberto90-debug/WerkstattKalender
   oeffnen und anmelden.
2. Rechts in der Seitenleiste auf "Releases" klicken,
   dann auf "Draft a new release".
3. "Choose a tag" anklicken, eintippen:  v1.1
   und darunter "Create new tag: v1.1 on publish" waehlen.
4. Bei "Target" den Zweig  claude/jolly-bell-qmnsv0  waehlen
   (Klick auf das Auswahlfeld, Reiter "Branches").
5. Titel eintragen:

      BTA-Cockpit - Komplettpaket (Stand 21.09.2026)

6. In das Beschreibungsfeld den Text aus dem Kasten unten
   einfuegen (kopieren ab "Alles fuer einen...").
7. ZWEI Dateien in das Feld "Attach binaries by dropping
   them here" ziehen und WARTEN, bis beide Ladebalken
   fertig sind:
      BTA-Cockpit-Komplettpaket.zip          (ca. 110 MB)
      Werkstatt-Cockpit-Programm-win64.zip   (ca. 110 MB)
   Die zweite ist das nackte Programm-ZIP aus dem Ordner
   01-Programm - sie ist noetig, damit das Werkzeug sie
   sich mit dem Knopf "Programm herunterladen" selbst
   holen kann.
8. Auf den gruenen Knopf "Publish release" klicken.

----------------------------------------------------------
 SCHRITT 3: Einmal pruefen
----------------------------------------------------------
Diesen Link im Browser oeffnen - der Download muss sofort
starten:

https://github.com/ciraciroberto90-debug/WerkstattKalender/releases/latest/download/BTA-Cockpit-Komplettpaket.zip

Startet er, ist der Ein-Link-Weg fuer alle Zeiten aktiv.

----------------------------------------------------------
 RELEASE-TEXT ZUM EINFUEGEN (Schritt 2, Punkt 6)
----------------------------------------------------------
Alles fuer einen neuen Rechner in EINER Datei: das Programm,
das BTA-Cockpit-Werkzeug (ein richtiges Fenster mit fertig
ausgefuellten Pfaden und Knoepfen fuer Einrichten,
Herunterladen, Pfade speichern, Verbindung pruefen und
Entfernen), die fertige Einstellungs-Datei und die
Anleitung als PDF.

So geht es:
1. BTA-Cockpit-Komplettpaket.zip herunterladen (unten bei
   "Assets") und auf dem Rechner entpacken.
2. Im entpackten Ordner BTA-Cockpit-Werkzeug.cmd
   doppelklicken und im Fenster den gruenen Knopf
   "Einrichten" druecken (die Pfade stehen schon drin).
3. Desktop-Verknuepfung "Werkstatt-Cockpit" doppelklicken.
   Beim allerersten Start meldet sich Windows-SmartScreen:
   "Weitere Informationen" -> "Trotzdem ausfuehren".

Keine Adminrechte noetig, nichts wird im Windows-Sinn
installiert - den Programm-Ordner loeschen entfernt alles
wieder. Leser-Rechner werden genau gleich eingerichtet.
(Die zweite Datei Werkstatt-Cockpit-Programm-win64.zip ist
nur fuer das Werkzeug selbst - zum Einrichten immer das
Komplettpaket nehmen.) Fragen an Roberto Ciraci (Werkstatt).

----------------------------------------------------------
 SPAETERE STAENDE
----------------------------------------------------------
Bei einer neuen Programm-Fassung: neues Release mit dem
naechsten Tag (v1.2, v1.3, ...) anlegen und BEIDE ZIPs
unter den GLEICHEN Dateinamen anhaengen. Die festen
".../releases/latest/..."-Links zeigen dann automatisch auf
den neuesten Stand - kein Link muss je angepasst werden,
und der Knopf "Programm herunterladen" im Werkzeug holt
von selbst die neueste Fassung.
